# 2026IOT_project

## 프로젝트 개요

이 프로젝트는 사용자가 설정한 알람 시간에 맞춰 물 섭취를 유도하고, 실제 물 섭취 여부를 로드셀 무게 변화로 판단하는 IoT 알람 시스템이다.

앱은 알람 시간 설정과 기록 확인을 담당하고, 라즈베리파이는 앱과 아두이노 사이에서 알람 정보와 섭취 결과를 관리한다. 아두이노는 로드셀과 HX711을 통해 컵의 무게 변화를 측정하고, 기준 무게 대비 150g 이상 감소했을 때 물 섭취 성공으로 판단한다.

## 주요 구성

- Mobile App
  - 알람 시간 설정
  - 알람 기록 확인
  - 물 섭취 성공 여부 표시

- Raspberry Pi
  - 앱과 아두이노 사이의 중계 역할
  - 알람 정보 관리
  - 섭취 결과 저장 및 전달

- Arduino
  - 로드셀 무게 측정
  - 버튼 입력으로 기준 무게 저장
  - 물 섭취 성공 여부 판단
  - LCD 상태 메시지 출력

## 물 섭취 판단 기준

기준 무게 대비 컵의 무게가 150g 이상 감소하면 물을 충분히 마신 것으로 판단한다.

단, 컵을 든 상태처럼 무게가 0~30g 근처일 때는 성공으로 판단하지 않고, 컵이 다시 받침대에 올라온 뒤 안정된 무게를 기준으로 판단한다.

## 현재 진행 상황

- 로드셀 + HX711 연결 및 보정 완료
- LCD 연결 테스트 완료
- 버튼을 이용한 기준 무게 저장 구조 구현 예정
- 아두이노 단독 테스트 후 라즈베리파이 연동 예정
- 앱 알람 설정 및 기록 화면 구현 진행 중

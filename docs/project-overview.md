# 프로젝트 개요

## 프로젝트 주제

물 섭취 여부를 로드셀 무게 변화로 판단하는 IoT 알람 시스템

## 개발 목적

이 프로젝트는 사용자가 알람 시간에 실제로 물을 마셨는지 확인하기 위해 로드셀을 사용한다. 단순히 알람을 끄는 방식이 아니라, 컵의 무게 변화가 일정 기준 이상 발생해야 물 섭취 성공으로 판단하는 구조이다.

## 전체 구성

- 앱: 알람 시간 설정, 알람 기록 확인
- 라즈베리파이: 앱과 아두이노 사이의 중계 및 데이터 관리
- 아두이노: 로드셀 무게 측정, 기준 무게 저장, 물 섭취 판단
- LCD: 현재 상태 안내
- 버튼: 알람 시작 후 기준 무게 설정

## 핵심 판단 기준

알람이 울린 뒤 사용자가 버튼을 누르면 현재 컵과 물의 무게가 기준 무게로 저장된다. 이후 컵을 들어 물을 마시고 다시 올려놓았을 때, 기준 무게보다 150g 이상 감소하면 물 섭취 성공으로 판단한다.

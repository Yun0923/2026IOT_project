# Day 02 - 아두이노 하드웨어 구성 및 단독 테스트 계획

## 오늘 진행한 작업

오늘은 IoT 물 섭취 알람 시스템에서 아두이노가 담당하는 역할과 현재 연결된 하드웨어 구성을 정리하였다.

아두이노는 로드셀과 HX711을 이용해 컵의 무게를 측정하고, 버튼 입력을 통해 기준 무게를 저장한 뒤, 사용자가 물을 마신 후 컵을 다시 올려놓았을 때 무게 감소량을 계산한다.

현재 프로젝트에서는 기준 무게 대비 150g 이상 감소했을 때 물 섭취 성공으로 판단한다.

## 현재 하드웨어 구성

현재 아두이노 쪽에서 사용하는 주요 부품은 다음과 같다.

- Arduino Uno
- Load Cell
- HX711 로드셀 증폭 모듈
- 1602 LCD
- 푸쉬버튼
- 점퍼선
- 컵 받침대 구조

## 각 부품의 역할

### 1. Arduino Uno

아두이노는 센서값을 읽고 전체 판단 로직을 실행하는 역할을 한다.

주요 기능은 다음과 같다.

- 로드셀 무게 측정
- 버튼 입력 감지
- 기준 무게 저장
- 컵 들림 상태 감지
- 컵 복귀 상태 감지
- 물 섭취 성공 여부 판단
- LCD 상태 메시지 출력
- 라즈베리파이에 결과 전달

### 2. Load Cell + HX711

로드셀은 컵과 물의 무게 변화를 측정한다.

HX711은 로드셀에서 발생하는 작은 전기 신호를 아두이노가 읽을 수 있는 디지털 값으로 변환하는 역할을 한다.

현재 프로젝트에서는 컵의 무게가 감소한 정도를 이용해 사용자가 물을 마셨는지 판단한다.

### 3. 푸쉬버튼

푸쉬버튼은 알람이 울린 뒤 기준 무게를 저장하는 용도로 사용한다.

사용자가 버튼을 누르면 현재 컵과 물의 무게가 기준 무게로 저장된다.

이 버튼은 알람 종료 버튼이 아니다.

알람 종료는 반드시 로드셀의 무게 감소 판단을 통해서만 처리한다.

### 4. LCD

LCD는 현재 시스템 상태를 사용자에게 안내하는 역할을 한다.

예상 표시 문구는 다음과 같다.

- Alarm Ready
- Alarm On
- Press Button
- Base Set
- Drink Water
- Cup Lifted
- Return Cup
- Checking
- Success
- Not Enough

## 물 섭취 판단 흐름

아두이노에서 처리할 물 섭취 판단 흐름은 다음과 같다.

1. 알람 시작 신호를 받는다.
2. LCD에 알람 시작 상태를 표시한다.
3. 사용자가 버튼을 누른다.
4. 현재 컵과 물의 무게를 기준 무게로 저장한다.
5. 사용자가 컵을 들어 물을 마신다.
6. 무게가 0~30g 근처로 떨어지면 컵이 들린 상태로 판단한다.
7. 컵이 다시 받침대 위에 올라오면 최종 무게를 측정한다.
8. 기준 무게와 최종 무게의 차이를 계산한다.
9. 150g 이상 감소했으면 물 섭취 성공으로 판단한다.
10. 150g 미만이면 물을 더 마셔야 하는 상태로 판단한다.

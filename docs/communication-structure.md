# 통신 구조 정리

## 통신 구조 개요

본 프로젝트는 앱, 라즈베리파이, 아두이노가 각각 역할을 나누어 동작하는 IoT 물 섭취 알람 시스템이다.

전체 구조는 다음과 같다.

```text
[Mobile App]
알람 시간 설정
알람 기록 확인
물 섭취 성공 여부 표시

        ↓

[Raspberry Pi]
알람 정보 관리
아두이노에 알람 시작 신호 전송
아두이노로부터 물 섭취 성공 결과 수신
앱에 결과 전달 및 기록 저장

        ↓

[Arduino]
로드셀 무게 측정
버튼 입력으로 기준 무게 저장
물 섭취 성공 여부 판단
LCD 상태 메시지 출력

## 진행 내용

- 앱의 역할을 알람 설정 및 기록 확인으로 정리하였다.
- 라즈베리파이의 역할을 알람 정보 관리와 아두이노 중계로 정리하였다.
- 아두이노의 역할을 로드셀 측정, 기준 무게 저장, 물 섭취 판단으로 정리하였다.
- 라즈베리파이와 아두이노는 USB Serial 통신을 사용하는 방향으로 정리하였다.
- 물 섭취 성공 시 아두이노가 라즈베리파이에 `DRINK_SUCCESS` 메시지를 보내는 구조로 정리하였다.

# 통신 구조 정리

## 통신 구조 개요

본 프로젝트는 앱, 라즈베리파이, 아두이노가 각각 역할을 나누어 동작하는 IoT 물 섭취 알람 시스템이다.

전체 구조는 다음과 같다.

```text
[Mobile App]
알람 시간 설정
알람 기록 확인
물 섭취 성공 여부 표시

        ↓

[Raspberry Pi]
알람 정보 관리
아두이노에 알람 시작 신호 전송
아두이노로부터 물 섭취 성공 결과 수신
앱에 결과 전달 및 기록 저장

        ↓

[Arduino]
로드셀 무게 측정
버튼 입력으로 기준 무게 저장
물 섭취 성공 여부 판단
LCD 상태 메시지 출력
